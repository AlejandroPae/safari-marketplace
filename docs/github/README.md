# GitHub: tu fork y el CI

Esta guía deja listo **tu fork** del repositorio, con GitHub Actions
habilitado y las credenciales que el CI necesita para publicar tus imágenes
en Docker Hub. Esas imágenes son las que después despliega Dokploy
([`docs/dokploy/`](../dokploy/README.md)).
